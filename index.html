    Tipos de node

    Os pesos começam no padrão do papel escolhido, na escala em que 1 = um node comum de Ataque +3; os nodes únicos (%) valem de 16 a 35 pelo dano estimado. Os pesos das habilidades vêm da seção “Minhas habilidades”. O peso diz o quanto você quer aquele tipo no caminho (0 = indiferente). “Obrigatório” força pegar todos os nodes daquele tipo nesta árvore. Para obrigar só um node específico, clique nele na board.

      Critério

      Em 0, menos pontos sempre vence e o peso só desempata caminhos de mesmo custo. Acima de 0, o caminho aceita gastar esse tanto de pontos a mais para cada 1,0 de peso que ganhar.
